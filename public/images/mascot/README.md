# Mascotte robot TROIE

Déposez ici les GIFs de la mascotte. Ils sont utilisés automatiquement via le
composant `src/components/Mascot.tsx`.

Fichiers attendus :

- `robot.gif`, version idle (affichée sur la page /formations et le dashboard).
- `robot-success.gif`, version réussite (affichée quand un QCM est réussi).

Tant qu'un fichier est absent, la mascotte ne s'affiche pas (aucune image
cassée). Dès qu'il est présent, il apparaît sans autre changement de code.
