# Règles maison TROIE

**ZÉRO em-dash.** Jamais le caractère em-dash (U+2014) nulle part : ni dans
la copie, ni dans le code, ni dans les commentaires, ni dans les messages de
commit.
Remplacer par virgule, deux-points, point, parenthèses, ou supprimer.
Les en-dashes `–` et tirets `-` sont autorisés. Cette règle est non négociable.

**FR avec accents.** Toute la copie utilisateur est en français correctement
accentué (`grâce à`, `découverte`, `très`, `déjà`, `méthode`, etc.).
Les slugs, identifiants de code, et noms de fichiers restent en ASCII.
